
# Dynamic Island PC

A modern Windows application that brings the interactive **Dynamic Island** experience directly to your desktop. It acts as a sleek, floating island that can be positioned anywhere on your screen, packing useful widgets, tools, and shortcuts into a compact interface.

---

## 💡 What It Does & How It Works

By default, the floating island discreetly shows core status elements:

* **Core Status:** Displays the current time and battery percentage.
* **Media Tracking:** Automatically detects if media is playing and shows what is currently active.
* **Free Positioning:** You can drag and place the island anywhere on your screen.
* **Expanded View (Double-Click):** Double-clicking the island expands it into a full panel. Inside, you can use the **X** button in the top-right corner to close the app, or click the minimize button (alternatively, double-clicking the island again minimizes it back).

---

## 🗂️ Expanded Panel & Tabs Breakdown

When you double-click the island to open the main panel, you will find the following tabs:

1. **Media Tab:**
* Shows playback progress, along with play, pause, and skip controls.
* *Status:* Features a volume bar, though it is still under development and not functional yet.


2. **Daily AI Chat Tab:**
* A simple yet functional AI chat to answer quick questions throughout your day.
* *Requirement:* Requires an active internet connection.


3. **Screen Translation Overlay Tab:**
* Designed to translate the current page or screen content.
* *Status:* Currently in early development and barely functional, as it has a strict 500-character limit while most pages easily exceed it.


4. **File Search Tab:**
* Allows you to search for any file on your PC directly from the interface.


5. **Basic File Converter Tab:**
* A handy tool for converting files between formats.
* *Supported Formats:* `.docx`, `.jpg`, `.png`, `.pdf`, `.txt`, `.html`, `.csv`, and `.bmp`.
* *Note:* May run into issues depending on complex files, but works well for simple conversions.


6. **Shortcuts Page:**
* Displays pre-programmed shortcuts and lets you add your own.
* *Known Limitation:* Currently, added shortcuts reset every time you close the app (plans to add a removal feature and permanent saving are underway).


7. **Tools & Weather Tab:**
* Quick shortcut to open the system snipping/capture tool.
* Shows local temperature (if incorrect, you can manually type your city name).
* Displays battery level and real-time CPU usage.
* Toggles whether the app should launch automatically with Windows.



---

## 🚀 How to Use

1. Go to the **Releases** section of this repository.


2. Download the `DynamicIslandPC.zip` file.
3. Extract the contents of the `.zip` file to a folder of your choice.
4. Open the extracted folder and run `DynamicIslandPC.exe` to start the application.

## 🛠️ Requirements

* **Operating System:** Windows 10 or 11.


* **.NET Runtime:** You must have **.NET** installed on your machine for the application to execute properly.
